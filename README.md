# ClearDesk

ClearDesk 是一個免登入、local-first 的日常待辦與決策整理工具。它把快速記錄、時間視角、優先級與標籤放在同一個安靜的工作區，所有資料都留在使用者自己的瀏覽器中。

## 功能

- 快速新增、編輯、完成與刪除事項
- 今天／本週／稍後／收件匣／已完成檢視
- 高、中、低優先級與截止日期狀態
- 自訂標籤、搜尋、狀態／優先級／到期篩選
- 明暗主題、鍵盤快捷鍵
- JSON 匯出與匯入備份
- 零依賴、零後端、可靜態部署

## 開發

```bash
npm run build
python3 -m http.server 3000 --bind 0.0.0.0
```

開啟 `http://localhost:3000/` 即可使用。建置輸出會放在 `dist/`。
